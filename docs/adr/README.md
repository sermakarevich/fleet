ADRs capture important decisions and why.
Each ADR is one dated note in this folder.
Number files 0001, 0002, and so on.
Never reuse or reorder a number once used.
New proposals start with Status: Proposed.
Update Status to Accepted or Superseded later.
Link the code and docs the decision affects.
Keep plain language; explain abbreviations first.
Old ADRs stay for history; never delete one.
Start file names with the zero-padded number.
